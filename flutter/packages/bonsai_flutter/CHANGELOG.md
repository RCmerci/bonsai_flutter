# Changelog

## 0.1.0-dev.1

- Added the typed in-memory frame model and transactional `NodeStore`.
- Added the bounded binary frame codec and producer-owned cross-language
  fixtures with byte-for-byte clean checks.
- Added protocol 1.1 through 1.4 widget, text-input, host-effect, navigation,
  environment, and native-extension slices.
- Added protocol 1.12 semantic opacity animation with a node-scoped
  `AnimationController`, completion events, reduced-motion behavior, and
  backward-compatible 1.x minor decoding.
- Added typed native factory registration, capability/version fallback,
  node-scoped resources, and fixed-extent VirtualList virtualization.
- Connected the built-in request-focus and scroll-to host effects to
  node-scoped renderer resources.
